# ADR 0004: The tool is dark only

Status: accepted
Date: 2026-11-04

## Context

Early design work showed light and dark themes. Every style decision costs time in both themes, and the tool is meant to be small and finished.

## Decision

Dark only. Colours, contrast checks and screenshots are made for dark. CSS variables are still used for colours so a light theme can be added later.

## Consequences

Half the visual testing. Users who want a light page do not get one in version 1.
